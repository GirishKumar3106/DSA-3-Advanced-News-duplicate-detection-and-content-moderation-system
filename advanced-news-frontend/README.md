# Advanced News Intelligence System — Frontend

React + Vite frontend for the Spring Boot backend.

## Run

```powershell
npm install
npm run dev
```

Open `http://localhost:5173` while the Spring Boot backend is running on `http://localhost:8080`.

## Includes

- Dashboard and backend status
- Verify News with online coverage + Fact Check evidence
- Search live news
- Inspect raw fact-check results
- DSA Workspace: ArrayList/file-backed news management, duplicate detection, KMP moderation, HashMap categorization, HashMap + PriorityQueue trending, and Graph + BFS related news
- Larger presentation-friendly typography
- Clear distinction between direct and related fact-check evidence
